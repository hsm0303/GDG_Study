# WIL
---
이번 시간에는 DDD에 대해서 좀 더 깊게 배우는 시간을 가졌다. 도메인별로 신경 쓸 게 많기 때문에 DDD를 써야 하며 DDD라는 것 자체가 도메인에 집중하라는 뜻이라는 것을 배웠다.
entity와 value object의 차이에 대해서도 배웠다. entity는 다른 것들이 바뀌어도 절대 바뀌지 않는 것이며 value object는 값이 같으면 같은 것이라는 차이가 있다는 것을 알았다. 만원이 여러 장 있다고 어떤 만원은 오천원이 되는 것이 아니라 다 같은 가치를 가진 만원이라는 예시를 통해 쉽게 이해할 수 있었다. 객체를 만드는 이유가 규칙을 표현하기 위함을 알게 되었다.
주문이라는 택배 상자 안에 주문 항목, 개수 이런 것들이 들어있으며 여기에서 택배 상자가 Aggregate를 뜻함을 알게 되었다. aggregate끼리는 서로의 내부를 마음대로 바꾸지 못하게 하기 위해서 ID로만 참조한다는 사실을 알았다.
불변식을 배울 때 여러 객체에 불변식일 걸쳐져 있다면 그 객체들은 하나의 aggregate에 있음을 뜻한다는 것도 배웠다.
정적 팩토리 메서드를 통해 조건식이 존재하여 불변식을 지킬 수 있다는 사실을 알았다.
long보다 BigDecimal를 쓰는 이유는 BigDecimal의 불변성 때문이 아닐까라고 생각한다. BigDecimal에 대해서 찾아보니 객체 내부의 값이 변경되는 것이 아니라 연산 결괏값을 갖는 새로운 객체가 생성되어 반환된다는 사실을 알았다. 이를 통해 더 안전하다고 생각하여 long보다 BigDecimal을 선호하는 것 같다고 생각한다.
